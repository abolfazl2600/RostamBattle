# چک‌لیست تأیید موبایل — ایشوی ۱۱

**وضعیت انتشار موبایل: در انتظار تأیید روی دستگاه واقعی.** شبیه‌سازی Chromium/لمس جای اجرای بازی روی Android Chrome و iPhone Safari را نمی‌گیرد. تا تکمیل ردیف‌های الزامی زیر، ایشوی ۱۱ باز است و ادعای پشتیبانی نهایی منتشر نمی‌شود.

## ماتریس دستگاه‌ها

| بستر | مدل / نسخهٔ سیستم‌عامل | مرورگر / نسخه | نتیجهٔ یک نبرد کامل | عملکرد، صدا و وقفه‌ها | وضعیت |
|---|---|---|---|---|---|
| گوشی Android — الزامی | ثبت نشده | Chrome؛ ثبت نشده | اجرا نشده | اندازه‌گیری نشده | در انتظار دستگاه |
| iPhone — الزامی | ثبت نشده | Safari؛ ثبت نشده | اجرا نشده | اندازه‌گیری نشده | در انتظار دستگاه |
| iPad — در صورت دسترسی | ثبت نشده | Safari؛ ثبت نشده | اجرا نشده | اندازه‌گیری نشده | در انتظار دستگاه |
| تبلت Android — در صورت دسترسی | ثبت نشده | Chrome؛ ثبت نشده | اجرا نشده | اندازه‌گیری نشده | در انتظار دستگاه |
| مرورگر نرم‌افزاری با شبیه‌سازی لمس | Chromium / WebGL نرم‌افزاری | محیط توسعه | مسیر UI و ورودی بررسی شده؛ برد UI با fixture | معیار FPS یا گرمای دستگاه نیست | فقط بررسی مرورگری |

برای هر اجرای واقعی، commit یا نشانی دقیق نسخه، مدل دستگاه، سیستم‌عامل، نسخه مرورگر، اندازهٔ CSS viewport، نسبت تصویر، پروفایل کیفیت، مرحله/شخصیت/سختی، مدت اجرا و نتیجه را بنویسید. هیچ ردیف خالی به‌صورت پیش‌فرض Pass محسوب نمی‌شود.

## ۱. نمایش و ناوبری

- [ ] گوشی 16:9، گوشی حدود 19.5:9 و تبلت حدود 4:3 در حالت افقی بررسی شوند؛ Safe Area و نوار مرورگر هیچ کنترل ضروری را نپوشاند.
- [ ] در حالت عمودی، تمام بازی با ابعاد Landscape جابه‌جا‌شده، ۹۰ درجه بچرخد و کل صفحه را پر کند؛ پیام چرخش یا توقف به علت جهت نمایش داده نشود (#31).
- [ ] نمایش طبیعی و چرخیده: محل لمس دکمه‌ها، سه لمس هم‌زمان، اسکرول فهرست/اطلاعات، Safe Area، باز و بسته‌شدن نوار مرورگر و resize سریع بررسی شوند.
- [ ] عنوان ← حالت ← فصل/چالش ← سختی ← شخصیت ← مقدمه ← نبرد، بدون کیبورد طی شود.
- [ ] فهرست‌های بلند اسکرول شوند، دکمه‌های پایین پنل نتیجه قابل دسترسی باشند و لمس منو حمله یا Pointer Lock نسازد.
- [ ] توقف، ادامه، خروج با تأیید، شکست/پیروزی، نتیجه و تلاش دوباره/بازگشت بررسی شوند.
- [ ] منوی داستان فعلی فقط نمونهٔ موقت اشکبوس را اجرا کند؛ چهار کارت به‌زودی حتی با سیو قدیمی قابل اجرا نباشند. چالش‌های قفل‌شده از سیو واقعی یا ذخیرهٔ QA جداگانه و مشخص استفاده کنند.

## ۲. مبارزه

- [ ] حرکت هشت‌جهته و سرعت آنالوگ؛ رهاکردن جوی‌استیک فوراً حرکت را قطع کند.
- [ ] زنجیرهٔ N1 تا N6 و Chargeهای ترکیبی با زمان‌بندی واقعی، پرش/حملهٔ هوایی و جاخالی اجرا شوند.
- [ ] موسو پس از پر شدن نوار اجرا شود و وضعیت دکمه با آماده‌بودن هماهنگ باشد.
- [ ] Target/recenter و چرخاندن دوربین مستقل از جوی‌استیک عمل کنند.
- [ ] هوانگ ژونگ: نگه‌داشتن قدرتی ← aim ← کشیدن برای هدف ← رهاکردن و شلیک.
- [ ] سه لمس هم‌زمان حرکت + دوربین + حمله/قدرتی، بدون گم‌شدن انگشت یا اجرای دوبارهٔ اکشن.

## ۳. وقفه و بازیابی

- [ ] هنگام نگه‌داشتن حرکت و حمله، اعلان‌ها/Notification Shade باز و بسته شوند؛ هیچ ورودی معلقی باقی نماند.
- [ ] رفتن به پس‌زمینه و برگشت، تعویض تب، تماس/وقفه سیستم و چرخش افقی↔عمودی بررسی شوند.
- [ ] پس از وقفهٔ سیستم/پس‌زمینه، برگشت نیاز به ادامهٔ صریح داشته باشد؛ تغییر جهت به‌تنهایی Pause نکند و لمس‌های قبلی پاک شوند.
- [ ] صدای اولین تعامل، mute/unmute دستگاه و بازیابی صدای Safari/Chrome پس از وقفه آزموده شوند. نتیجهٔ «بدون صدا» با وضعیت mute و volume ثبت شود.
- [ ] قطع WebGL، پیام روشن و گزینهٔ Reload/کیفیت سبک بدهد؛ هیچ سیو تأییدشده‌ای پاک نشود. اگر امکان شبیه‌سازی قطع روی دستگاه نیست، این خانه «اجرا نشده» بماند.

## ۴. عملکرد و نبرد کامل

- [ ] حداقل ۵ دقیقه نبرد شلوغ، همراه با Story و Trial، با ثبت پروفایل کیفیت اجرا شود؛ تعداد دشمنان برای بهترشدن گزارش تغییر نکند.
- [ ] FPS/زمان فریم با ابزار توسعهٔ مرورگر، در صورت دسترسی، ثبت شود؛ میانگین و افت‌های محسوس جدا باشند. نبود ابزار اندازه‌گیری صریحاً نوشته شود؛ از حدس یا FPS شبیه‌ساز به‌عنوان عدد گوشی استفاده نشود.
- [ ] کیفیت خودکار/سبک/متعادل، resize و چرخش بدون سفیدشدن بوم بررسی شوند. گرمای محسوس، افت پس از چند دقیقه و حافظه، در صورت قابل مشاهده‌بودن، ثبت شوند.
- [ ] هدف اولیه ۳۰ FPS گوشی و نزدیک ۶۰ FPS تبلت قوی صرفاً هدف است؛ حد نهایی پذیرش با دادهٔ دستگاه انتخاب می‌شود، نه تضمین برای همهٔ سخت‌افزارها.
- [ ] حداقل یک Android و یک iPhone یک Battle کامل را بدون کیبورد به پایان برسانند و مدل/مرورگر/نتیجه ثبت شود. بردن با invulnerability، تقویت آسیب یا تزریق رویداد، تأیید این بند نیست.

## بررسی‌های موجود

`node checks/mobile-input.mjs`، `node checks/fa-localization.mjs`، `node checks/campaign.mjs`، `node checks/trials.mjs`، `node src/chars/check.mjs`، `node checks/shared-originality.mjs` و `node src/world/changban.check.mjs` برای بررسی کد قابل اجرا هستند. این‌ها نتیجهٔ تست سخت‌افزار نیستند. تست‌سوییت جدیدی برای این چک‌لیست اضافه نشده است.

## قالب ثبت یک اجرا

- دستگاه / OS / مرورگر:
- commit / URL / تاریخ:
- viewport / Safe Area / نسبت تصویر:
- مرحله، شخصیت، سختی و کیفیت:
- مدت و نتیجهٔ واقعی نبرد:
- FPS و روش اندازه‌گیری / حافظه / گرما:
- لمس هم‌زمان / rotate / background / صدا:
- Pass / Fail / اجرا نشده برای موارد بالا:
- باگ مسدودکننده، مراحل بازتولید و تصویر/ویدئو:

سیوها متعلق به همان origin مرورگر هستند؛ برای تست رکورد، از پروفایل QA جدا استفاده کنید و سیو شخصی را پاک نکنید. برای اجرای محلی با گوشی، سرور روی شبکهٔ خصوصی با نشانی رایانه در همان Wi-Fi باز شود؛ نیاز به بسته‌بندی اپ یا تغییر سرویس انتشار نیست.
